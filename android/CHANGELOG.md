## 0.4.0

- First native Jetpack Compose SDK release, with a REST client, localized survey
  UI, visibility rules, image answers, CAPTCHA callbacks, and AI follow-ups.
- Add a complete inquiry flow with encrypted anonymous sessions and three-month
  local history, admin replies, and new-reply checking.
- Retain survey sessions across host recreation, preserve completed image
  uploads, and release unused image preview resources.
- Convert unsupported inquiry images to JPEG and show image thumbnails in inquiry
  history and detail views.
- Build with Android API 37, AGP 9.5, Gradle 9.8.2, Kotlin 2.4.21, and updated
  Compose, serialization, and HTTP dependencies.
